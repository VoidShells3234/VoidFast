Сюда размещается файл установщика VoidSetup.exe.

На сайте ссылки ведут на /download/VoidSetup.exe — файл должен лежать в этой
папке и называться именно так. Рядом лежит VoidSetup.exe.sha256: это
контрольная сумма установщика, которая показывается на странице install.html.

Если установщик слишком большой для текущего хостинга, загрузите его во внешнее
файловое хранилище или релиз-платформу (например, GitHub Releases, Cloudflare R2,
S3-совместимое хранилище) и замените ссылки /download/VoidSetup.exe в HTML на
прямую публичную ссылку. Хеш SHA-256 на странице должен соответствовать
публикуемому файлу.
