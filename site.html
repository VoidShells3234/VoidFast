О сайте

Это простая статическая страница проекта VoidFast: описание браузера, статус alpha и страница установки.

Статический сайт

Сайт состоит из обычных HTML, CSS и JS файлов. Его можно разместить на любом статическом хостинге.

Страница загрузки

На странице установки есть кнопка скачивания установщика и базовые системные требования.

Без лишних зависимостей

Сайт не использует внешние скрипты и шрифты — стили, картинки и JS лежат в папке site.

Локальный режим

Сейчас сайт настроен для локального запуска. Для просмотра используйте start-site.cmd или python site\server.py.

Подготовка к хостингу

Структура сайта статическая, поэтому его можно выложить как обычные файлы. Перед публикацией нужно будет указать реальный домен и место, откуда будет скачиваться установщик.
